# FitFlow Changelog

## [1.0.0] - 2026-10-01
### Добавлено:
- Расчёт общего тоннажа тренировки.
- Вычисление 1RM (одноповторного максимума) по формуле Эпли.
- Подсчёт ИМТ (Индекса массы тела) и определение категории.
- Автоматическое тестирование (CI/CD) через GitHub Actions.

### Изменено:
- Проведен рефакторинг архитектуры (разделение на модули user_manager, workout_manager).
